Frames & Spatial Orientation Time-Trial

Analyze 20 randomized geometric frame puzzles under time-trial conditions. Mentally rotate or invert the inner scene to upright orientation and determine the corresponding marker (1–5).

Test Instructions

  1. Observe the object inside the central window and determine its spatial rotation or reflection relative to its normal upright position.
  2. Apply the exact same spatial transformation to the small reference marker embedded in the surrounding frame.
  3. Select which of the 5 numbered symbols (1, 2, 3, 4, 5) matches the transformed reference marker.
  4. All 20 frame puzzles (a through t) are shuffled randomly on every run.

Controls & Shortcuts

  1. Mouse Selection: Click answer box [1–5] directly below the frame image.
  2. Keyboard Shortcuts: Press keys 1 to 5 to select an answer, and ← / → arrow keys to switch items.
  3. Review Navigation: Jump directly to any question using the numbered pills in the bottom bar.
  4. Submit: Click END at any time to finalize the test and review detailed breakdowns.
